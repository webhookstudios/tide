# Tide 1.1.0

Tide is the new name for Swell. It now has the Sedge look shared by every webhookstudios app: one set of colors, fonts and icons, in light and dark mode.

- New icon, colors and fonts. Window titles and headings use the Sedge serif.
- The top-bar menu's settings item now says Tide Settings.
- The top-bar icon and the app icon now match.
- The package and command are now called `tide` (it was `swell`). Installing it replaces the old package.
- If Swell was turned on, Tide turns on in its place the next time you log in.
- Everything works exactly as before. Your settings and presets carry over.

Install:

```bash
sudo apt install ./tide_1.1.0_all.deb
```
